# Sistem Informasi E-Persuratan (Kelompok 11)
Aplikasi berbasis web (PHP Native & MySQL) untuk mendigitalisasi pencatatan surat masuk, penerbitan surat keluar, dan pelacakan lembar disposisi instansi.

- **Yunus Robani (202343501292)** — `feature/surat-keluar-arsip` (Manajemen Surat Keluar & Arsip)

## Cara Menjalankan Aplikasi
1. Clone repository: `git clone https://github.com/Qarimm/sistem-e-persuratan-kel11..git`
2. Impor database `db_epersen.sql` ke MariaDB/MySQL
3. Sesuaikan konfigurasi koneksi database pada file `config/database.php`
4. Jalankan server lokal dan buka `http://localhost:8000`
